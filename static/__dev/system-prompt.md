
Build SkillConnect, a polished local skill and job marketplace for daily-wage workers in Kalaburagi, Karnataka, India. It is a CSE final-year resume project. Customers search, book, chat with, review and report workers. Workers create profiles, accept/decline jobs, complete jobs and see earnings. Admins verify workers, moderate reviews, resolve complaints, manage users and view analytics. Support English, Kannada and Hindi; warm modern mobile-first UI; secure role-based authentication; validated forms; shareable worker search filters; worker profiles and availability; booking lifecycle with double-booking protection; fake-review detection; per-booking chat; notifications; worker/customer dashboards; admin panel; analytics and charts; fair-price estimator; Leaflet/OpenStreetMap map; accessible UI, escaped output, tests and documentation. Demo seed data should include around 17 realistic workers across skills and Kalaburagi localities, 10 customers, completed bookings/reviews, pending requests and demo logins. Important platform constraint: implement using Floot's supported React/TypeScript pages, serverless endpoints and managed Postgres rather than Node/Express/SQLite, because Floot hosts typed project files and serverless endpoints. Deliver a genuinely working end-to-end application, not a static mockup.
